## 🎯 Project Mission

The Latency Recorder project aims to democratize precise timing measurements in neuroscience research. By providing an open-source, affordable solution, we enable researchers worldwide to:

- 🔬 Measure stimulus presentation latency with millisecond precision
- 🧠 Improve the quality of time-sensitive neuroscience experiments
- 💡 Share knowledge and collaborate on timing solutions
- 🌍 Make precision timing accessible to all research labs

The main problem is that there is an unknown time delay between trigger and stimulus, but EEG studies assume this delay is 0ms.

```bash
Visual stimulus: code -> OS -> gpu -> monitor
Trigger: code -> OS -> trigger device -> amplifier
```

Requirements are that the device should be affordable and work across a wide variety of EEG labs (different hardware).
